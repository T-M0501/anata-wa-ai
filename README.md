# あなたはAIです

スマートフォンのブラウザ（iPhone の Safari、Android の Chrome）で遊べるゲームです。
インターネットから何も読みこまないので、このフォルダだけで動きます。

## フォルダの中身

| なまえ | なに？ |
|---|---|
| `index.html` | ゲーム本体（これ1つで動きます） |
| `images/` | イラスト置き場（あとで絵を入れる場所） |
| `問題パターン.md` | 必要なイラストの一覧と、問題のしくみの説明 |
| `設計メモ.md` | ゲームのアイデアのメモ |
| `test.js` | 問題がまちがっていないかを確かめるための道具（遊ぶときは使いません） |

## まず自分のパソコンで遊んでみる

`index.html` をダブルクリックすると、ブラウザでゲームが開きます。

## GitHub Pages で公開する方法（スマホで遊べるようにする）

1. **GitHub に登録する**
   https://github.com を開いて「Sign up」から無料で登録します。
2. **新しい置き場所（リポジトリ）を作る**
   右上の「＋」→「New repository」をおします。
   - 「Repository name」に好きな名前を入れます（例：`anata-wa-ai`）。
   - 「Public」をえらびます。
   - 下の緑の「Create repository」をおします。
3. **ファイルを入れる**
   できたページの「uploading an existing file」という青い文字をおします。
   このフォルダの中身（`index.html`、`images` フォルダ、`README.md` など）を、まとめて画面にドラッグします。
   下の緑の「Commit changes」をおします。
   ※ `index.html` がいちばん上（フォルダの中ではなく、すぐ見える場所）にあることを確かめてください。
4. **公開の設定をする**
   リポジトリの上にある「Settings」→ 左の「Pages」をおします。
   「Branch」のところで `main` と `/(root)` をえらんで「Save」をおします。
5. **1〜2分まつ**
   同じページの上に `https://（あなたのなまえ）.github.io/anata-wa-ai/` のようなアドレスが出ます。
   これをスマホで開けば遊べます。家族や友だちにも、このアドレスを送れば遊んでもらえます。

### イラストをあとから入れるとき

リポジトリの `images` フォルダを開いて「Add file」→「Upload files」から PNG を入れ、「Commit changes」をおします。
数分たつと、ゲームの絵が入れかわります（スマホでは、ページを開きなおしてください）。

## 遊びかた

1. タイトル画面で「こども」か「おとな」をえらびます。
2. むずかしさ（かんたん／ふつう／むずかしい）をえらびます。
3. ジャンル（① 絵を見て判断／② 文章を読む／③ 表を読む）をえらびます。
4. 指示書とレベルをえらんで、スタートします。

アドレスの最後に `#kids` をつけると こども用、`#adults` をつけると おとな用のページから始まります。

## ふたりで遊ぶとき

1. ひとりはタイトル画面で「ふたりモード」をオンにして遊びます（お題を見る人）。
2. もうひとりは、べつのスマホで同じアドレスを開き、「📖 指示書だけ 表示」をおします。
3. こども／おとな・むずかしさ・ジャンル・指示書・レベルを、お題の画面と同じにそろえて、話しあって答えます。

アドレスの最後に `#manual` をつけると、はじめから指示書だけの画面が開きます。
（例：`#manual-bus-2-normal` … こどもの「バスの時こく表」レベル2・ふつう）
